# 🎪 Mor Tente Web Sitesi

Profesyonel, mobil-uyumlu, admin panelli tente hizmetleri web sitesi.

## 🎯 Özellikler

✅ **Mobil-First Tasarım**
- Responsive design
- Bottom navigation (ekranın altında menü)
- Tüm cihazlarda mükemmel uyum

✅ **5 Ana Sayfa**
- Ana Sayfa (Hero bölümü)
- Hakkımızda
- Galeri
- İletişim
- Instagram

✅ **Admin Panel**
- Tam responsive design
- Dashboard (istatistikler, mesajlar)
- Ayarlar (renk, telefon, email, vs.)

✅ **Teknolojiler**
- HTML5
- CSS3 (Flexbox/Grid)
- Vanilla JavaScript
- Font Awesome Icons

## 🚀 Başlangıç

### 1. Siteyi Aç

`index.html` dosyasını tarayıcıda aç

### 2. Admin Paneline Gir

- URL: `admin/index.html` veya sağ üstteki ⚙️ Admin butonu
- Kullanıcı Adı: `admin`
- Şifre: `admin 368900+`

## 📂 Dosya Yapısı

```
mor-tente-web-sitesi/
├── index.html                  # Ana sayfa
├── admin/
│   ├── index.html             # Admin giriş
│   └── dashboard.html         # Admin paneli
├── assets/
│   ├── css/
│   │   ├── style.css          # Ana stiller
│   │   └── admin.css          # Admin stiller
│   └── js/
│       ├── main.js            # Ana JavaScript
│       └── admin.js           # Admin JavaScript
└── README.md
```

## 🎨 Admin Panelden Yapılabilecekler

✏️ Tema rengini değiştir
📞 İletişim bilgilerini güncelle
🏢 Şirket bilgilerini düzenle
📊 Dashboard istatistiklerini gör

## 🔐 Güvenlik

- Admin şifresi: `admin 368900+`

## 📱 Responsive Breakpoints

- **Mobile**: < 480px
- **Tablet**: 480px - 768px
- **Desktop**: > 768px
